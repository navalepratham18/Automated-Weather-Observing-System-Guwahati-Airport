# Airport Pipeline Template

Copy this directory to `<CITY>_airport_pipeline` before processing a new
airport. Keep source data, generated data, reports, scripts, notebooks, and
model artifacts in their dedicated directories. The complete operating
procedure is in the repository-root [`instructions.md`](../instructions.md).

Replace every `<CITY>` and `<city>` placeholder in scripts, notebooks, and
reports before running the pipeline.
